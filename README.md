# K-VIBE STUDIO

K컬처 웹사이트를 기획하고 AI로 제작한 뒤, Canva CD 키링과 NFC로 연결하는 학생 활동 중심 4차시 수업 웹사이트입니다.

**제작·기획: 잇윗(IT with)**

## 수업 구성

1. 기획하기: K컬처 주제 선택, 기획 카드 작성, AI 제작 요청서 자동 생성
2. 웹사이트 만들기: Gemini 제작·수정, Google Sites 게시, 접속 주소 확인
3. 키링 디자인: Canva 디자인과 CD 키링 조립
4. NFC 연결: 기종별 NFC 안내, URL 기록, 친구와 작품 테스트

## 실행

별도 설치나 빌드 없이 `index.html`을 열거나, 이 폴더를 정적 웹사이트로 배포합니다. 배포 시 시작 파일은 루트의 `index.html`입니다.

- `index.html`: 페이지와 활동지
- `style.css`: 반응형 디자인
- `app.js`: 활동지·복사·저장·다운로드 기능
- `assets/`: 조립 사진과 게시·NFC 안내 이미지

입력 내용은 사용자의 브라우저에 저장됩니다. 서버로 전송하거나 수집하지 않습니다. 브라우저 정책에 따라 자동 저장이나 클립보드 사용이 제한될 수 있습니다.

사진·화면 자료는 수업 참고용으로 제공된 자료를 반영했습니다. 코드와 포함 자료의 이용 권한을 별도로 확인해 주세요.
